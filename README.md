# Machine Learning Engineer — Training Projects Portfolio

**OpenClassrooms × CentraleSupélec** (2022-2023)

This repository showcases selected projects from my Machine Learning Engineer training program, demonstrating practical applications across deep learning, computer vision, NLP, and data science.

---

## 🎯 Projects Overview

### [📊 Project 01 — Public Health Nutrition Analysis](./project-01-foodfacts/)
**Data Cleaning & Exploratory Analysis**

Analyzed OpenFoodFacts database to support public health initiatives through nutritional data insights.

- **Dataset**: OpenFoodFacts (900k+ products)
- **Key Work**: Data cleaning, outlier detection, multivariate analysis
- **Methods**: Statistical analysis, PCA, visualization
- **Impact**: Identified data quality issues and nutrition patterns for health recommendations

### [⚡ Project 02 — Energy Consumption Prediction](./project-02-energy/)
**Regression & Feature Engineering**

Predicted building energy consumption based on characteristics and location.

- **Dataset**: Building energy benchmarks (Seattle)
- **Key Work**: Feature engineering, regression modeling, performance optimization
- **Methods**: Linear regression, ensemble methods, cross-validation
- **Results**: Accurate consumption prediction for energy efficiency planning

### [🛒 Project 03 — E-commerce Customer Segmentation](./project-03-segmentation/)
**Clustering & Business Analytics**

Segmented e-commerce customers to enable targeted marketing strategies.

- **Dataset**: UK online retail transactions
- **Key Work**: RFM analysis, clustering, segment profiling
- **Methods**: K-means, hierarchical clustering, DBSCAN
- **Outcome**: Actionable customer segments for personalized campaigns

### [💬 Project 04 — Automatic Question Categorization](./project-04-nlp-questions/)
**Natural Language Processing & API Development**

Built NLP system to automatically categorize technical questions by topic.

- **Dataset**: Stack Overflow questions
- **Key Work**: Text preprocessing, topic modeling, supervised classification, API deployment
- **Methods**: TF-IDF, LDA, supervised ML (Logistic Regression, SVM)
- **Deliverable**: REST API for real-time question categorization

### [🖼️ Project 05 — Image Classification with Deep Learning](./project-05-image-classification/)
**Deep Learning & Computer Vision**

Developed CNN-based image classifier with custom architecture.

- **Dataset**: Image dataset (domain TBD from notebooks)
- **Key Work**: CNN architecture design, training optimization, transfer learning
- **Methods**: Custom neural network, data augmentation, hyperparameter tuning
- **Implementation**: Python implementation with PyTorch

### [🔬 Project 06 — Deep Learning for Digital Image Correlation](https://github.com/Thomas-Durand-Texte/DIC-Neural-Networks)
**Advanced Computer Vision & Materials Science**

Developed CNN-based system to accelerate material deformation analysis using Digital Image Correlation (DIC).

- **Dataset**: Synthetic speckle patterns with Hermite FEM deformations
- **Key Work**: Custom CNN architectures, synthetic data generation, experimental validation
- **Methods**: U-Net variants, compound scaling, iterative refinement
- **Results**: **420× speedup**, **6.6× better resolution** vs classical methods
- **Publication Quality**: Full technical report with experimental validation

> 📍 **Note**: This project is maintained in its [own repository](https://github.com/Thomas-Durand-Texte/DIC-Neural-Networks) due to its scope and publication-quality presentation.
